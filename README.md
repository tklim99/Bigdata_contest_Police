# 지역 치안 안전 데이터 분석 경진대회
https://www.bigdata-policing.kr/board/b_contest/view?idx=167&category=

충남,세종,대전 지역 교통사고 분석 및 예측 

<br/>

## 1. 배경 & 목적

- 우리가 길을 걷거나, 운전할 때 교통사고가 발생하는 것을 종종 확인 할 수 있습니다. 교통사고는 그만큼 우리 주변에서 흔하게 일어나는 사고이며 목숨을 잃을 정도의 위험성을 가지고 있습니다. 또한 활용한 데이터의 3,849,381건 중 교통사고는 264,448건으로 전체 14.5% 가량 비중을 차지고 있으며, 적게 일어나는 사고가 아님을 알 수 있습니다. 

- 교통사고의 원인은 안전운전 불이행, 중앙선침범, 신호위반 등의 원인이 존재하는데 이전 교통사고의 데이터를 통해 교통사고가 자주 발생하는 구역에는 어떠한 원인이 존재하는지 분석할 필요가 있습니다.

<br/>

## 2. 주최/주관 & 팀원

- 주최/주관: 경찰대학교 치안정책연구소
- 팀원: 이시현, 이지훈, 임태경

<br/>

## 3. 프로젝트 기간

- 2023.01. ~ 2023.02. (3주)

<br/>

## 4. 프로젝트 소개

<img src='./img/지역 치안 안전 경진대회.png' width='100%' height='80%'>

 교통사고 발생 지역의 데이터를 분석하고 시각화하는 과정에서, 제공된 데이터를 전처리한 후, 다양한 기법을 활용하여 지역별로 사고 건수를 추출하고 시각화하였습니다.

- 데이터 전처리

제공된 데이터는 KP_2020, KP_2021, NPA_2020 데이터로 구성되었습니다. 이 과정에서 불필요한 컬럼들을 제거하고, 널값을 처리하여 분석에 적합한 데이터셋을 구축하였습니다. 널값이 존재하는 컬럼들인 RPTER_SEX, HPPN_X, HPPN_Y, SME_EVT_YN을 제거하여 데이터의 신뢰성을 높였습니다.

- 데이터 통합 및 지역별 추출

전처리된 데이터를 기반으로 CCTV 데이터를 하나의 DataFrame으로 통합하였으며, 충남, 대전, 세종 지역을 기준으로 데이터를 나누어 저장하였습니다. 또한, 교통사고 데이터를 위·경도를 기준으로 충남, 대전, 세종 지역으로 추출하는 과정을 통해 분석의 정확성을 높였습니다.

- 중복 데이터 처리

중복된 데이터를 제거하여 보다 신뢰성 있는 결과를 도출하였습니다. 충남, 대전, 세종 지역에서 각각의 중복 데이터를 처리한 후, 최종적으로 데이터의 중복성을 제거하여 분석에 활용하였습니다.

- 시각화

데이터 시각화는 Folium을 활용하여 교통사고 발생 지역을 시각화하였습니다. 이를 통해 충남, 대전, 세종 지역에서의 교통사고 발생 위치를 시각적으로 파악할 수 있도록 하였습니다. 또한, 지역별 CCTV 설치 현황을 마커로 표시하여 설치 구역을 시각화하였습니다.

- 결과

클러스터링 결과, CCTV가 없는 도로에서 사고가 더 빈번하며, 대형 교차로는 교통사고 다발 지역임이 확인되었습니다. CCTV만으로는 한계가 있어 추가 설치와 경찰력 배치가 필요합니다. 또한, 보차혼용도로와 골목의 사고 빈도 분석을 통해 사각지역 거울 설치 등 예방 조치를 강화할 수 있습니다. 이를 통해 교통사고와 사상자 수를 줄일 수 있을 것으로 기대됩니다.

<br/>

## 5. 프로젝트 담당 역할

- 지역별 교통사고 데이터를 공공데이터 포털에서 수집하여, 불필요한 컬럼을 제거하고 널값을 처리하여 분석에 적합한 데이터셋을 구축
- 위도, 경도를 기반으로 지역을 추출하는 변환 함수를 만들어 데이터를 정제
- Folium 라이브러리를 사용해 충남, 대전, 세종 지역의 교통사고 발생 위치를 마커로 표시하여 시각화
